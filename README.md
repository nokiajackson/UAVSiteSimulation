# FIELD / UAVSiteSimulation

React 19 + React Three Fiber + Three.js + Vite 的室內無人機場地原型。

## 開發

需要 Node.js 22.12+（目前以 Node.js 24 驗證）。

```sh
npm ci
npm run dev
```

Vite 預設使用 5173 埠。`npm run build` 建置；`npm run preview` 預覽建置結果。
`npm test` 驗證場地配置格式、儲存往返、座標轉換、穿越方向與路線衝突。

## 操作

拖曳旋轉、滾輪縮放、右鍵平移；支援透視／俯視／正視、重設視角、隱藏牆面與路線。
開始模擬後，由 01 H 起飛，依序經過 02 垂直圓環、03 拱門、04 垂直圓環、05 三環組（左水平 → 中垂直 → 右水平）、06 三旗 S 型繞行、07 隧道，然後回到 01 循環。旗子預設左 → 右 → 左繞行。可暫停、重設或調整速度、安全半徑。

## 編輯、儲存與載入

預設進入編輯模式；右上角「結束編輯／編輯場地」可切換。

- 點選 3D 物件，或在左側下拉選單選擇。H 起飛區、六個環／拱門、三面旗子、隧道、地板、牆面和每扇窗戶都能獨立編輯。支架隨所屬環移動，窗框隨窗戶移動。
- 「移動 W」使用 XYZ 軸線拖曳；「旋轉 E」使用圓弧拖曳。空白處拖曳維持視角操作，使用控制軸時暫停視角操作。
- 可輸入 XYZ 位置（公尺）和 XYZ Euler 角度（度），按 Enter 或移開焦點套用。位置以物件原點為準，例如環中心、旗子和隧道底部。旋轉繞物件原點。
- 吸附可開關：移動 0.1 m，旋轉 15°。位置限制在 ±100 m，角度限制在 ±3600°。
- **Save 儲存**：以版本化 JSON 存在目前網址的瀏覽器 `localStorage`；重新整理／再次開啟會自動載入。不是寫入 GitHub 或伺服器。
- **Reload 載入**：還原此瀏覽器上次按 Save 的配置；未儲存修改會先詢問是否捨棄。
- **匯出 JSON／匯入 JSON**：交換 `uav-layout.json`，跨電腦、瀏覽器或網址時使用。匯入不會自動覆寫本機儲存，需再按 Save。匯入會檢查版本、完整物件清單、ID、類型及有效座標；錯誤檔案會保留目前配置。
- 「恢復預設配置」會詢問確認；只有再次 Save 才會覆寫原本的儲存。瀏覽器停用儲存時可改用 JSON 匯出。

路線在拖曳放開或數值套用後依物件的新位置、旋轉重算；包含環的穿越法向量、旗子左右繞行座標和隧道的進出方向。每次修改會暫停並重設動畫。若取樣檢查發現路線與環、支架、旗子、隧道、地板或牆面相交，會列出衝突並停用播放；仍可儲存配置，再調整障礙位置消除衝突。這個版本不會自動搜尋繞開任意新增衝突的替代路線。

## 場地與路線限制

依參考照片及使用者白板建立七個編號區域，鏡中物件未重複加入。單位為公尺，位置和尺寸為示意，並非測量重建。預設物件與幾何資料在 `src/layout.js`，路線計算位於 `src/planner.js`。

路線依 01～07 順序通過：前三個垂直開口沿 -Z 穿越，第 05 關左水平環向上、中垂直環沿 +X、右水平環向下穿越；旗子位於右側，以左、右、左的固定繞行側通過；隧道沿 +Z（俯視圖上下方向）穿過後從前側通道返回 H。拱門限制穿越點位於上半圓。安全半徑可調整 0.30～0.35 m，小型無人機的顯示尺寸已縮至對應範圍。

每個環前後 0.60 m 設平行於法向量的穿越線段，以安全半徑與 0.10 m 環緣餘量縮減可用開口，透過逐步縮小步長的座標搜尋降低折線總長。第 05 關兩側水平環向中間靠近，左右水平環高度為 2.60 m、中間垂直環中心高度為 1.40 m，並對三環實體環緣進行路線取樣間距檢查（取樣間距不超過 0.08 m，額外保留 0.045 m 餘量）。第 07 關整體向左移至 X = 3.1 m，洞口方向維持不變。三旗繞行點包含旗寬、機身安全半徑和 0.15 m 額外側向餘量。介面距離為 01 到 07 隧道出口，不含返回 H；比較基準是相同固定繞旗、隧道路線搭配各環中心穿越。

這是指定拓撲與固定繞行點下的幾何近似，沒有搜尋旗子兩側所有路線，也不是完整場地的全域最短路線證明。路線測試涵蓋穿環順序、環內安全範圍、拱門半圓限制、三旗繞行方向、全迴圈對旗面的取樣間距、隧道入口出口及循環閉合。

動畫沿折線等速移動，尚未模擬轉彎半徑、加速度、姿態、氣流、電量及連續碰撞偵測。精確規劃前需現場尺寸、障礙位置與無人機飛行限制，不能直接用於實機導航。

路線衝突檢查為每段不超過 0.06 m 的球形機身取樣近似，不等同物理引擎或連續碰撞保證；隧道屋頂以理想半圓曲面近似實際分段模型。固定順序和進出點可能在編輯後無法通行，介面會保留可編輯配置並標示衝突，不宣稱為可飛的全域最短路線。
